01 Objetivo

CAI tiene un cliente puntual pidiendo ver sus reportes fuera del Excel, ahora. Le pusimos nombre a este proyecto: Radar. Esta propuesta cubre su primera etapa, un prototipo funcional, local, conectado a los datos de ese cliente, con las plantillas de reportería que ya están definidas.

Radar crece por etapas. Este primer paso es acotado a un cliente y a lo esencial. La plataforma replicable para los más de 50 clientes de CAI (motor, API de datos) sigue siendo un camino válido, pero se retoma más adelante, a medida que sumamos clientes y necesidades.

02 Alcance
Dónde vive y cómo se accede
  • Todo localEl prototipo corre en un servidor dentro de la red de CAI, conectado a una base MySQL que CAI provee en ese mismo servidor.
  • Mismo acceso de siempreEl cliente entra por el mismo punto donde hoy revisa su Excel (red local o VPN). No se construye un sistema de acceso nuevo.
  • Autenticación simpleUsuario y contraseña, reutilizando el mismo esquema de permisos que ya usa el cliente hoy.
Qué se entrega
  • Plantillas de reportería en HTMLSobre el catálogo de módulos ya trabajado (KPIs, margen, ventas, detalle). CAI define cuáles de esos módulos entran en esta primera entrega.
  • Tres páginas de muestraCon datos reales de este cliente, para que el equipo de CAI las revise y las use con él.
  • Vista responsiveSe ve bien en celular, no solo en escritorio.
  • Exportar a PDF y a CSV/ExcelCada reporte se puede descargar como PDF o como archivo de datos, para trabajarlo fuera de Radar si se necesita.
Desarrollo

EVO Communication Lab construye las plantillas HTML y las conecta a la base MySQL, para que muestren datos reales del cliente en vez de datos de muestra.

Fuera de este alcance

Esta entrega no incluye el motor o la API pensada para replicar el sistema en los otros clientes de CAI, ni gráficos dinámicos avanzados, ni un servicio de reportería mensual. Todo eso queda como conversación pendiente, a retomar según cómo funcione este primer prototipo.
